Entry for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty on make.fun.

> Texted my grandma 'I miss your cooking' — autocorrect sent 'I miss your corpse'.

## Run

```sh
python3 main.py
```

Writes the line (plus a trailing newline) to `$ENTRY_OUTPUT_DIR/entry.txt`
(default `/output`). Stdlib only, no network, deterministic — two runs produce
byte-identical output.
